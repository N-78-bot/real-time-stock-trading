# Real-Time Stock Trading System (기획 단계)

> ⚠️ **기획 프로젝트**: 이 레포지토리는 실시간 주식 거래 시스템의 기획 문서만 포함하고 있습니다. 실제 구현은 아직 진행되지 않았습니다.

## 📋 프로젝트 목표

대용량 실시간 트래픽 처리를 학습하기 위한 프로젝트 기획

## 📝 현재 상태

- **진행도**: 기획 단계 (0% 구현)
- **문서화**: 요구사항 분석, 기술 스택 선정, 아키텍처 설계
- **구현**: 미진행

## 🎯 학습 목표

- Kafka를 활용한 실시간 데이터 처리
- WebSocket 기반 실시간 통신
- Redis를 활용한 고속 캐싱
- Kubernetes를 통한 Auto Scaling

## 📖 기획 문서

기획 과정과 의사결정 과정은 `/docs` 폴더에서 확인할 수 있습니다.

## 💡 Note

이 프로젝트는 학습 목적의 기획 단계이며, 실제 구현은 LiveMart 프로젝트에서 유사한 패턴으로 적용 중입니다.
